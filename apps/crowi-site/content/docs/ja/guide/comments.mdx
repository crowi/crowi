---
title: コメント
description: ページにコメントを残す
---

Crowi の各ページには **コメント** を残せます。コメントはページ本文の下に
新しい順で表示され、編集の意図を伝えたり、レビューや議論をしたりするのに
使えます。

## コメントを書く

ページ本文の下にコメントセクションがあります。テキストを入力して送信すると、
コメントが追加されます。

- コメントは、そのページに **アクセス権のあるユーザー** が投稿できます。
  公開範囲が限定されたページでは、grant チェックを通過したユーザーだけが
  コメントできます。
- コメントは投稿時の **最新リビジョンに紐づけて** 保存されます。あとから
  ページが更新されても、コメント自体はそのとき参照していたリビジョンを
  指し続けます。

> **Note**: ゴミ箱に入っている(論理削除済みの)ページでは、コメント
> セクションは読み取り専用になり、新規コメントは投稿できません。

## コメントとアクティビティ・通知

コメントを投稿すると、Crowi 内部でいくつかの連動処理が走ります。

- ページの **コメント件数** が更新されます。
- **アクティビティ** が記録され、それを起点に **通知** が生成されます。
  通知は、そのページの作成者・過去のコメント投稿者・過去のリビジョン
  作成者など、ページに関わったユーザーに届きます。

通知の仕組みについては [通知](./notifications) を参照してください。

## コメントを削除する

投稿したコメントは削除できます。

- コメントを削除するには、対象ページへの **アクセス権が必要** です。
- コメントを削除すると、それに対応するアクティビティも一緒に取り除かれます。

## コメントの表示

コメントセクションには次の情報が表示されます。

| 項目 | 内容 |
| ---- | ---- |
| 投稿者 | コメントを書いたユーザー |
| 本文 | コメント本文 |
| 投稿日時 | コメントが投稿された日時 |

コメントはページごとに、新しいものが上に来る順で並びます。
