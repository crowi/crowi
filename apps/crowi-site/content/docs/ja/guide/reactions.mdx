Crowi には、ページに対する軽量なアクションがいくつか用意されています。
ブックマーク・いいね・ウォッチ・既読(seen-by)です。
それぞれ目的が違うので、このページで使い分けを説明します。

## ブックマーク

ブックマークは「あとで読む / よく使うページに印を付ける」ための機能です。

- ブックマークは **自分専用** です。誰がブックマークしても、他の人には
  影響しません。
- 自分がブックマークしたページは、ユーザーページ配下のブックマーク一覧
  (`/user/<ユーザー名>/bookmarks`)でまとめて見られます。
- 同じページを重ねてブックマークしても二重に登録されません。

ブックマークはページ表示画面から付け外しできます。

## いいね

いいねは、ページに対する **共有のリアクション** です。

- 何人がいいねしたかがページに表示されます。ブックマークと違い、いいねは
  全員に見えます。
- すでにいいね済みのページにもう一度いいねしても二重にはカウントされません。
  いいねを取り消すこともできます。
- いいねするとアクティビティが記録され、それをもとに通知が
  作られます。いいねを取り消すと、アクティビティも取り除かれます。

> **Tip**: ブックマークは「自分用のしおり」、いいねは「みんなに見える評価」
> と考えると使い分けやすくなります。

## ウォッチ

ウォッチは、ページの更新通知を受け取るかどうかを制御する機能です。

ウォッチ状態には次の 2 つがあります。

| 状態 | 意味 |
| ---- | ---- |
| WATCH | このページの通知を受け取る |
| IGNORE | このページの通知を受け取らない |

- ウォッチ状態を一度も自分で設定していないページでは、デフォルトの
  状態が自動で決まります。ページの作成者・コメント投稿者・リビジョン
  作成者として関わっていれば「ウォッチ中」、関わっていなければ
  「ウォッチしていない」として扱われます。
- ウォッチする / しないを自分で設定すると、それ以降はその設定が優先されます。
  自動判定に戻す操作はありません。

## 既読(seen-by)

ページを閲覧すると、自分が **既読ユーザー(seen-by)** として記録されます。

- ページにアクセスすると、自動的に自分が既読リストに追加されます。
- 既読リストには「このページを誰が見たか」が記録され、既読人数が表示
  されます。
- 同じユーザーが何度ページを開いても、既読は重複して登録されません。

既読は「ページがチームにどれくらい読まれているか」を把握するための
情報です。明示的な操作は不要で、閲覧するだけで自動的に記録されます。

## 4 つのアクションの違い

| アクション | 公開/非公開 | 主な目的 | 自動/手動 |
| ---------- | ----------- | -------- | --------- |
| ブックマーク | 自分専用 | あとで読む・お気に入り | 手動 |
| いいね | 全員に見える | ページへの評価・反応 | 手動 |
| ウォッチ | 自分専用 | 更新通知の受信設定 | 手動(デフォルトは自動判定) |
| 既読 | 全員に見える | 閲覧の記録 | 自動 |
