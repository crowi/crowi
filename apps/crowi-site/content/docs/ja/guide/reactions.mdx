Crowi には、ページに対する軽量なアクションがいくつか用意されています。
**ブックマーク**・**いいね**・**ウォッチ**・**既読(seen-by)** です。
それぞれ目的が違うので、使い分けを整理して紹介します。

## ブックマーク

ブックマークは「あとで読む / よく使うページに印を付ける」ための機能です。

- ブックマークは **自分専用** です。誰がブックマークしているかは他の人には
  影響しません。
- 自分がブックマークしたページは、ユーザーページ配下のブックマーク一覧
  (`/user/<ユーザー名>/bookmarks`)から一覧できます。
- 同じページを重ねてブックマークしても二重登録されません(冪等です)。

ブックマークはページ表示画面から付け外しできます。

## いいね

いいねは、ページに対する **共有のリアクション** です。

- いいねはページの `liker` リストとして記録され、ページに「何人がいいねを
  したか」が表示されます。ブックマークと違い、いいねの状態は全員に見えます。
- すでにいいね済みのページにもう一度いいねしても二重にはカウントされません
  (冪等です)。いいねを取り消すこともできます。
- いいねすると **アクティビティ** が記録され、それを起点に **通知** が
  生成されます(取り消すとアクティビティも取り除かれます)。

> **Tip**: ブックマークは「自分用のしおり」、いいねは「みんなに見える評価」
> と考えると使い分けやすくなります。

## ウォッチ

ウォッチは、ページの更新通知を受け取るかどうかを制御する機能です。

ウォッチ状態は次の 2 つを取りえます。

| 状態 | 意味 |
| ---- | ---- |
| WATCH | このページの通知を受け取る |
| IGNORE | このページの通知を受け取らない |

- ウォッチ状態を一度も明示的に設定していないページについては、**デフォルト
  状態が自動的に判定** されます。ページの作成者・コメント投稿者・リビジョン
  作成者として関わっていれば「ウォッチ中(WATCH)」、関わっていなければ
  「ウォッチしていない」として扱われます。
- ウォッチ状態を明示的に WATCH / IGNORE に設定すると、それ以降は設定値が
  優先されます。
- 現状の API は WATCH / IGNORE の 2 状態のみで、「明示設定を解除して
  デフォルト判定に戻す」操作は提供されていません。

## 既読(seen-by)

ページを閲覧すると、自分が **既読ユーザー(seen-by)** として記録されます。

- ページにアクセスすると、自動的に自分が既読リストに追加されます。
- 既読リストには「このページを誰が見たか」が記録され、既読人数が表示
  されます。
- 同じユーザーが何度ページを開いても、既読は重複登録されません(冪等です)。

既読は「ページがチームにどれくらい読まれているか」を把握するための
情報です。明示的な操作は不要で、閲覧するだけで自動的に記録されます。

## 4 つのアクションの違い

| アクション | 公開/非公開 | 主な目的 | 自動/手動 |
| ---------- | ----------- | -------- | --------- |
| ブックマーク | 自分専用 | あとで読む・お気に入り | 手動 |
| いいね | 全員に見える | ページへの評価・反応 | 手動 |
| ウォッチ | 自分専用 | 更新通知の受信設定 | 手動(デフォルトは自動判定) |
| 既読 | 全員に見える | 閲覧の記録 | 自動 |
