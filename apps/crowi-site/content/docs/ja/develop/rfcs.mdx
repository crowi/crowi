## RFC を読むには

各 RFC は冒頭にステータス・ターゲットリリース・依存する RFC を記したメタデータブロックを持ち、続いて Summary / Goals / Non-goals / 詳細設計という構成になっています。実装がどこまで進んでいるかは、この索引ではなく各 RFC のメタデータブロックが正です。
