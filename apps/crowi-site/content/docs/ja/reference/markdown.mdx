Crowi のページ本文で使える記法の早見表です。各記法の詳しい説明と例は [Markdown 記法](../guide/markdown) にあります。

## 標準の記法

CommonMark と GitHub Flavored Markdown はそのまま使えます。

| 記法 | 意味 |
| --- | --- |
| `# 見出し` 〜 `###### 見出し` | 見出し。目次とアンカー ID が自動で付く |
| `- 項目` / `1. 項目` | 箇条書き / 番号付きリスト |
| `**太字**` / `*斜体*` / `` `コード` `` | 強調とインラインコード |
| `[ラベル](/path)` | リンク |
| `![alt](url)` | 画像 |
| `> 引用` | 引用 |
| `\| 列 \| 列 \|` | 表 |
| ` ```lang ` | 言語付きのコードブロック。保存時にシンタックスハイライトされる |

## Crowi のコア拡張

プラグインなしで常に使えます。

| 記法 | 意味 |
| --- | --- |
| `[[/dev/setup]]` | wiki リンク。絶対パスへのリンクになる |
| `[[/dev/setup\|セットアップ手順]]` | 表示名を指定した wiki リンク |
| `[[/dev/setup#macos]]` | 見出しアンカー付きの wiki リンク |
| `[ラベル](/survey/AI%20ドラフト)` | スペースを含む path へのリンク (推奨のエスケープ) |
| `[ラベル](/survey/AI+ドラフト)` | 同じ意味。`+` をスペースとして解釈する |
| `[ラベル](</foo bar>)` | 同じ意味。山括弧でスペースをそのまま書く |
| `@username` | メンション。ユーザーページへのリンクになり、本人に通知が届く |
| `:smile:` | 絵文字ショートコードを Unicode 絵文字に変換する |
| `@[card](url)` | リンクカード。URL 先の OGP からカードを描画する |
| `@[tag](url)` | 埋め込みタグ。`tag` に対応するレンダラプラグインがあれば埋め込みになる |
| 段落中の裸の URL | 登録された展開ルールがあればリッチな埋め込みに展開される |
| `![alt](url){width=60% height= align= float=}` | 画像の表示属性。幅・高さ・整列・回り込みを指定する |
| `> [!NOTE]` | 種別つきの注意書き。`NOTE` / `TIP` / `IMPORTANT` / `WARNING` / `CAUTION` |
| ページ先頭の `---` ブロック | frontmatter。`キー: 値` の表として本文の上に描画される |

## レンダラプラグインが足す記法

対応するプラグインを有効にしたときだけ動きます。有効化の手順は [レンダラプラグイン](../operations/renderers) を参照してください。

| 記法 | 意味 | プラグイン |
| --- | --- | --- |
| `$a^2 + b^2 = c^2$` / `$$...$$` | LaTeX 数式 (インライン / ディスプレイ) | `@crowi/plugin-renderer-katex` |
| ` ```plantuml ` | PlantUML の図 | `@crowi/plugin-renderer-plantuml` |
| ` ```mermaid ` | Mermaid の図 | `@crowi/plugin-renderer-mermaid` |
| `##見出し` (`#` の直後に空白なし) | v1 の書き癖を見出しとして解釈する | `@crowi/plugin-renderer-crowi-legacy` |
