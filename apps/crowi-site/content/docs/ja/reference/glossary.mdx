ドキュメントは同じものを 1 つの呼び名で書きます。呼び名の正はこの表です。

## 用語

| 概念 | 呼び名 | 意味 |
| --- | --- | --- |
| ページ履歴の 1 件 | リビジョン | ページを保存するたびに 1 件作られる過去版。 |
| 自分の権限で API を呼ぶトークン | 個人アクセストークン | スコープと有効期限を指定して自分で発行する、長命のトークン。 |
| 設定画面のタブ | パスワード/APIトークン/アカウント連携 | パスワード変更・トークン発行・外部アカウント連携をまとめたタブ。 |
| 運用者が用意する起動用プロジェクト | runner プロジェクト | 使うプラグインと設定ファイルを持ち、Crowi 本体を起動する側のプロジェクト。 |
| 通知を外部サービスへ送る拡張 | 通知プラグイン | 通知の宛先を追加するプラグイン。 |
| ページの本文を HTML に変換する拡張 | レンダラプラグイン | 数式・図・独自記法などの変換を足すプラグイン。 |
| ファイルの保存先を差し替える拡張 | ストレージドライバ | 添付ファイルの保存先 (ローカル / S3 / GCS) を選ぶ実装。 |
