Crowi は Markdown ベースの Wiki アプリケーションです。チーム内のナレッジ共有のためのオープンソースソフトウェアとして開発されています。

## このドキュメントについて

このドキュメントでは、Crowi のセットアップから日々の利用、本番運用までを扱います。

- [はじめに](./getting-started) — Crowi をローカルで動かす
- [使い方ガイド](./guide/pages) — ページ・編集・検索などの利用者向けガイド
- [運用](./operations/installation) — インストール・設定・運用者向けガイド
- [プラグイン](./plugins/overview) — ストレージ / 検索 / レンダラの拡張
- [リファレンス](./reference/architecture) — アーキテクチャ・RFC・コントリビュート
