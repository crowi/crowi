Crowi は Markdown ベースの Wiki アプリケーションです。チーム内のナレッジ共有のためのオープンソースソフトウェアとして開発されています。

## このドキュメントについて

このドキュメントでは、Crowi のセットアップから運用までを扱います。

- [はじめに](./getting-started) — インストールとセットアップ
- [リアルタイム共同編集](./realtime-editing) — 複数ユーザーで同時にページを編集する
- [運用](./operations/realtime-collab) — 管理者向けのデプロイ / 運用ガイド
