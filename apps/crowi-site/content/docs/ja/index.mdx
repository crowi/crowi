Crowi は Markdown ベースの Wiki アプリケーションです。チーム内のナレッジ共有のためのオープンソースソフトウェアとして開発されています。

ページは Markdown で書き、共同編集・全文検索・コメント・通知でチームの知識をためていきます。

自分のサーバーに Docker で立てて運用でき、ストレージ・検索・レンダラはプラグインで差し替えられます。
