In Crowi, every user has their own "user page" where they can share their
profile and activity with the team. You can also change profile settings
such as your display name and avatar.

## User pages

Every user has a user page at `/user/<username>`. The page is laid
out as follows:

- A **cover** section at the top — a coloured cover band with the
  user's avatar, display name, `@username`, introduction, and a pair
  of stat pills (created pages count, bookmarks count).
- **Three tabs** below the cover:
  - **Pages** — pages the user has **created**. A page shows up here as
    long as this user created it, no matter where it lives (**creator-rooted**).
  - **Bookmarks** — pages the user has bookmarked.
  - **Subpages** — every page that **actually exists under**
    `/user/<username>/`, recursively across all depths, regardless of who
    created it (**path-rooted**). This is a different set from the
    "Pages" tab: a page another user created at, say,
    `/user/<username>/project` shows up here but not under "Pages"; and a
    page this user created outside `/user/<username>/` shows up under
    "Pages" but not here. The tab shows a 10-item preview plus the total
    count, with a "View all" link to a full listing that loads 30 at a
    time. Only pages the viewer is allowed to see (following the same
    grant rules as every other page listing) ever appear.

In addition, by Crowi convention the path `/user/<username>` itself
also works as a **wiki page**. If a page exists at this path, its body
is rendered **below the cover** alongside the tabs. This is useful when
you want to write a longer self-introduction in Markdown.

## Profile settings

Opening "Settings" from the user menu in the header lets you manage
profile-related settings in one place. The settings screen is split into
the following sections.

### Profile information

You can change your display name, email address, and display language.

| Field | Description |
| ----- | ----------- |
| Name | The name shown within the team |
| Email | The destination for notifications. If an administrator has configured a domain restriction for email addresses, an address that does not match the allow list cannot be saved |
| Language (lang) | The display language of the UI (Japanese / English) |

### Profile picture

You can upload or delete your profile picture (avatar). An uploaded image
is stored in storage and used as your user avatar throughout the app. If
you delete the image, it falls back to an avatar using the initials of
your display name.

### Password

You can change your login password. Users who only sign in via OAuth
(Google / GitHub) may not have a password set.

### API token

You can view and regenerate the API token used to access the Crowi API
from outside. Regenerating it invalidates the previous token.

> **Warning**: An API token is a secret as strong as your password. If you
> suspect it may have leaked, regenerate it promptly.
