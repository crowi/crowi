title: Comments

You can leave **comments** on every Crowi page. Comments are displayed below
the page body, newest first, and can be used to convey the intent of an edit
or to hold reviews and discussions.

## Writing a comment

There is a comment section below the page body. Enter text and submit, and
the comment is added.

- A comment can be posted by a user **with access rights** to the page. On a
  page with a restricted grant, only users who pass the grant check can
  comment.
- A comment is saved **tied to the latest revision** at the time of posting.
  Even if the page is updated later, the comment itself keeps pointing at the
  revision it referenced at that time.

> **Note**: On a page that is in the trash (soft-deleted), the comment
> section becomes read-only and new comments cannot be posted.

> **Note**: [Draft pages](./pages) do not have a comment section at all
> — drafts are creator-only and have no audience yet. The comments
> section appears once the draft is saved as a published page.

## Comments, activity, and notifications

When you post a comment, several linked processes run inside Crowi.

- The page's **comment count** is updated.
- An **activity** is recorded, and from it a **notification** is generated.
  The notification reaches users involved with the page — the page's creator,
  past comment authors, past revision authors, and so on.

See [Notifications](./notifications) for how notifications work.

## Deleting a comment

A comment you posted can be deleted.

- Deleting a comment requires **access rights** to the target page.
- When a comment is deleted, the corresponding activity is removed along with
  it.

## How comments are displayed

The comment section shows the following information.

| Item | Content |
| ---- | ------- |
| Author | The user who wrote the comment |
| Body | The comment body |
| Posted at | When the comment was posted |

Comments are ordered per page with the newest at the top.
