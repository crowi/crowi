Major design decisions for Crowi 2.0 are documented as **RFCs (Request for Comments)**. The documents themselves live under `docs/rfcs/` in the repository, and the numbers in the table below open them on GitHub.

This page is the index only. Summaries and implementation status belong to each RFC, so they are not repeated here.

## How to read the RFCs

Each RFC opens with a metadata block stating its status, target release and dependent RFCs, followed by Summary / Goals / Non-goals / detailed design. That metadata block, not this index, is the authority on how far the implementation has got.
