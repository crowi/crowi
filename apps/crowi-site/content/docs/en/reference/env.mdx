title: Environment variables
description: Every environment variable Crowi reads
---

Every environment variable the api and the web app read. The api validates the whole list at boot and reports malformed values and suspected typos in one consolidated report. For where to set them and how they are loaded, see [Configuration](../operations/configuration).

The four `NEXT_PUBLIC_` variables and `CROWI_API_URL` are read by the web app; everything else is read by the api.

| Variable | Default | What it does |
| --- | --- | --- |
| `AUTH_PUBLIC_API_URL` | the resolved web URL | Public origin of the api used to build external sign-in redirect URIs. Origin only — a path or query fails boot |
| `AUTH_PUBLIC_WEB_URL` | `CLIENT_URL` | Public origin of the web app used for the same redirect URIs. With both unset, [Signing in with an external account](../operations/federated-auth) is disabled |
| `BASE_URL` | — | Accepted as a known name only; the api never reads it. The public URL is `CLIENT_URL` |
| `CLIENT_URL` | (none) | Public origin of the web app. Used as the allowed CORS origin and to build links in outgoing mail. Boots without it, with a warning |
| `COLLAB_MAX_EDITORS_PER_PAGE` | `20` | Simultaneous editors allowed per page. Clients above the cap connect read-only |
| `CROWI_ARTIFACT_ORIGIN` | (none) | Origin-only separate-origin delivery target for HTML artifact pages. Requires `CLIENT_URL` to be set, and to a **different hostname** (a different port or scheme on the same hostname fails boot). A different registrable domain is recommended. Without it, separate-origin delivery stays off — see [Configuration](../operations/configuration) |
| `CROWI_API_URL` | (none) | URL the web server uses to reach the api through its built-in proxy. The published image does not re-read it at start, so it only applies in development and on Vercel |
| `CROWI_ENCRYPTION_KEY` | (none) | 32-byte master key (base64) that encrypts sensitive settings. Values are stored as plaintext when unset. Generate with `openssl rand -base64 32` |
| `CROWI_MIGRATE_USER` | (none) | Email address credited for page bodies a data migration rewrites. An admin is picked automatically when unset |
| `CROWI_MULTI_INSTANCE` | (none = single replica) | Declares a multi-replica deployment (`1` / `true` / a replica count). Only affects Redis/collab topology selection — `SECRET_TOKEN`'s required setting is unconditional whether this is set or not |
| `CROWI_UPLOAD_MAX_BYTES` | `52428800` (50 MB) | Attachment upload size limit in bytes. 50 MB is the ceiling; a larger value is clamped to it |
| `DEBUG` | (none) | When set, the boot report is printed one line at a time so it does not interleave with debug output |
| `ENABLE_DNSCACHE` | — | Accepted as a known name only; the api never reads it |
| `IMAGE_DERIVATIVE_ADMISSION_CONCURRENCY` | `2` | Thumbnails the upload paths may generate at the same time |
| `IMAGE_DERIVATIVE_ADMISSION_TIMEOUT_MS` | `5000` | How long (ms) an upload waits for a generation slot. Past it the thumbnail is skipped and the original is returned |
| `IMAGE_DERIVATIVE_MAX_PIXELS` | `50000000` | Largest image, in pixels, thumbnail generation will decode. Bigger images get no thumbnail |
| `JWT_ACCESS_TOKEN_TTL_SECONDS` | `3600` (1 hour) | Lifetime of the access tokens the api issues |
| `JWT_REFRESH_TOKEN_TTL_SECONDS` | `2592000` (30 days) | Lifetime of the refresh tokens the api issues |
| `MIGRATION_PREFLIGHT_UNAPPLIED_POLICY` | `block` | What to do when a preflight data migration is unapplied. `block` refuses to boot, `warn` boots with a warning. See [Upgrading](../operations/upgrade) |
| `MONGO_URI` | `mongodb://localhost/crowi` | MongoDB connection string. `MONGOLAB_URI` / `MONGODB_URI` / `MONGOHQ_URL` are read as the same value |
| `NEXT_PUBLIC_API_TIMEOUT_MS` | `20000` | How long (ms) the browser waits for an api response |
| `NEXT_PUBLIC_API_URL` | (none) | Absolute api origin as the browser sees it. Leave unset in a same-origin deployment |
| `NEXT_PUBLIC_ARTIFACT_ORIGIN` | (none) | Origin-only separate-origin delivery target for HTML artifact pages, as seen by the browser. Set to the same value as the api's `CROWI_ARTIFACT_ORIGIN` in a separate-origin deployment; every web replica must use the same value. Leave unset for same-origin delivery |
| `NEXT_PUBLIC_COLLAB_URL` | (none) | WebSocket URL the browser dials. Derived from the api origin and the browser's current origin when unset |
| `NODE_ENV` | `production` (also when unset) | `development` / `production` / `test` |
| `OAUTH_REFRESH_REUSE_GRACE_MS` | `60000` (60 s) | Grace window that suppresses rotation-reuse detection on refresh tokens. Capped at 5 minutes; `0` disables the grace |
| `PASSWORD_SEED` | (none) | Seed used to verify passwords stored in the pre-migration format |
| `PORT` | `4301` | Port the api server listens on. See [Ports and URLs](./ports) |
| `REDIS_KEY_PREFIX` | hostname of `CLIENT_URL` | Per-instance namespace prefixed to every Redis key and channel. See [Redis keys and ACL](./redis-keys) |
| `REDIS_REJECT_UNAUTHORIZED` | `1` | Set to `0` to skip certificate verification on a TLS Redis connection |
| `REDIS_URL` | (none) | Redis endpoint. Optional on a single replica, required with several. Use `rediss://` for TLS. `REDISTOGO_URL` / `REDIS_TLS_URL` are read as the same value. What uses it and under which keys is in [Redis keys and ACL](./redis-keys); what each feature does without it is in the section below |
| `SECRET_TOKEN` | **required** | The single signing secret for everything the api signs: Web session tokens, external-account access tokens and sign-in state, and the realtime collab / presence / notifications / mail tokens. Boot fails if it is unset, empty, whitespace-only, or a known placeholder. **At least 32 characters** — under `NODE_ENV=production` a shorter value also fails boot (other environments only warn). Every replica must share the same value. Generate with `openssl rand -base64 32`. The legacy `WS_TOKEN_SECRET` name is still read as a deprecated alias (checked first); if both are set to different values, boot logs a warning |
| `SLACK_MANIFEST_REQUEST_URL` | `CLIENT_URL` | Public origin written into the generated Slack app manifest. Set it when developing behind a tunnel |

## Behaviour without `REDIS_URL`

| Feature | Without `REDIS_URL` |
| --- | --- |
| Collaboration fan-out, presence, notifications, config sync | Cross-replica only, so a single replica loses nothing |
| Simultaneous-editor cap | Stops being enforced (fails open rather than turning people away) |
| Rate limiting | Keeps working in process memory (not shared across replicas) |
| Recently viewed pages | Unavailable — there is no fallback |
| Linking an external account | In-flight links live in the process, so restarting the api mid-link means starting that link again |

With several replicas `REDIS_URL` is required (see [Operating realtime collaboration](../operations/realtime-collab)).
