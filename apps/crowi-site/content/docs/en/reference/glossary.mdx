The documentation calls one thing by one name. This table is that name.

## Terms

| Concept | Name | Meaning |
| --- | --- | --- |
| One entry of a page's history | revision | The past version created every time a page is saved. |
| A token that calls the API as you | personal access token | A long-lived token you issue yourself, with a scope set and an expiry. |
| The tab in the settings screen | Password / API tokens / Linked accounts | The tab holding password changes, token issuing and external account links. |
| The project an operator builds to boot Crowi | runner project | The project that owns the plugin list and the config file and starts Crowi. |
| An extension that delivers notifications elsewhere | notifier plugin | A plugin that adds a destination for notifications. |
| An extension that turns page bodies into HTML | renderer plugin | A plugin that adds a conversion — maths, diagrams, extra syntax. |
| An extension that swaps where files are stored | storage driver | The implementation behind attachment storage (local / S3 / GCS). |
