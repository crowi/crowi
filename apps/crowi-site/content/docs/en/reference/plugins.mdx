The plugins maintained in the same repository as Crowi itself and published to npm. For how to install one, see [Installing and configuring plugins](../operations/plugins).

## Extensions you pick a driver for

Storage, search and mail each let you pick one "driver" — registered by a loaded plugin — in [crowi.config.json](./config-file).

| Kind | Driver name | Package | Configuration |
| --- | --- | --- | --- |
| Storage | `local` | `@crowi/plugin-storage-local` | [Storage](../operations/storage) |
| Storage | `s3` | `@crowi/plugin-storage-aws-s3` | [Storage](../operations/storage) |
| Storage | `gcs` | `@crowi/plugin-storage-gcs` | [Setting up GCS storage](../operations/storage-gcp) |
| Search | `mongo` | `@crowi/plugin-search-mongo` | [Search backend setup](../operations/search-setup) |
| Search | `elasticsearch` | `@crowi/plugin-search-elasticsearch` | [Search backend setup](../operations/search-setup) |
| Search | `opensearch` | `@crowi/plugin-search-opensearch` | [Search backend setup](../operations/search-setup) |
| Mail | `smtp` | `@crowi/plugin-mail-smtp` | [Mail delivery](../operations/mail) |
| Mail | `ses` | `@crowi/plugin-mail-aws-ses` | [Mail delivery](../operations/mail) |
| Mail | `resend` | `@crowi/plugin-mail-resend` | [Mail delivery](../operations/mail) |

`local`, `mongo` and `smtp` load on every boot without appearing in [crowi.config.json](./config-file).

## Extensions with no driver to pick

| Kind | Package | What it adds |
| --- | --- | --- |
| Renderer | `@crowi/plugin-renderer-katex` | Renders LaTeX maths |
| Renderer | `@crowi/plugin-renderer-plantuml` | Renders PlantUML diagrams |
| Renderer | `@crowi/plugin-renderer-mermaid` | Renders Mermaid diagrams |
| Renderer | `@crowi/plugin-renderer-crowi-legacy` | Reads the v1 writing habits |
| Authentication | `@crowi/plugin-google` | Signing in with a Google account |
| Integration | `@crowi/plugin-slack` | Expands Crowi page links shared in Slack into previews |
| Shared base | `@crowi/plugin-aws` | Holds the credentials the AWS plugins read; configuration only |
| SDK | `@crowi/plugin-api` | The types and interfaces for writing a plugin |

For the syntax the renderer plugins add see [Markdown syntax](./markdown), and for configuring them [Renderer plugins](../operations/renderers). Authentication and integration are configured in [Signing in with an external account](../operations/federated-auth) and [Slack integration](../operations/slack).

`@crowi/plugin-aws` is declared as a dependency by `@crowi/plugin-storage-aws-s3` and `@crowi/plugin-mail-aws-ses`, so there is no need to list it in [crowi.config.json](./config-file) yourself.
